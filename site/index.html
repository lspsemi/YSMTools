help常见问题

你可能想知道

lock打开加密 .ysm 会把内容保存下来吗？expand_more

不会。加密 .ysm 由 YSMParser 的 WebAssembly 版本在后台线程中解析，原文件和解密结果都不会写入磁盘。

verified预览效果和游戏里一样吗？expand_more

渲染、动画控制器和 Molang 的行为以 ModernYSM 源码为准逐项对齐，包括控制器执行顺序、状态过渡混合、未设置变量与除零等细节。加密模型还可以切换到原始面渲染模式，直接绘制文件中存储的面数据。

language不想安装，能在浏览器里用吗？expand_more

可以。克隆源码后运行 npm ci 和 npm run browser，会在本地启动并打开浏览器。部分桌面专属功能（如文件关联、资源管理器缩略图）只在 Windows 版中提供。

translate怎样添加新的界面语言？expand_more

复制程序目录下的 lang/en.lang，修改其中的语言信息并翻译各条目，放回 lang 文件夹，然后在顶栏的语言按钮中切换。

gavel可以免费使用和修改吗？expand_more

可以。YSM模型工具以 GPL-3.0-or-later 许可证开源，源代码托管在 GitHub 与 Codeberg。本工具是社区项目，并非 Yes Steve Model 官方出品。
